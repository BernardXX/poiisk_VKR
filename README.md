# Программное средство для подбора вакансий в сфере информационных технологий

1. В файл backend/.env надо вставить Secret key, полученный на сайте SuperJob: https://api.superjob.ru/register/ (Callback URL	указать http://localhost:5173)

2. В файл backend/token.txt надо вставить только Authorization key, полученный на сайте GigaChat API после регистрации: https://developers.sber.ru/portal/products/gigachat-api

3. Находясь в папке Poiisk_site (Например D:\Poiisk_site>) ввести pip install -r requirements.txt и npm install
